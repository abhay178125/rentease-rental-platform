# RentEase — Dark Indian Rental Marketplace

Client-side rental marketplace UI built with HTML5, CSS3, JavaScript, Bootstrap 5, jQuery, Font Awesome and Leaflet.js.

## Features in this UI foundation
- Dark Indian-inspired visual system
- Indian rental terminology: ₹, BHK, sq.ft, furnished status
- Home/property marketplace
- Search, filters and sorting
- Property details with Leaflet map
- Favorites with localStorage
- Client-side registration/login foundation
- Tenant, owner and admin dashboard foundations

## Data model
This version intentionally uses browser localStorage instead of a server/database. Data is local to the browser/device.

## Structure
- `index.html` — landing page
- `properties.html` — property marketplace
- `property-details.html` — property detail page
- `login.html`, `register.html` — client-side auth UI
- `dashboard/` — dashboard foundations
- `css/style.css` — complete theme
- `js/` — demo data, storage, property rendering and auth

Open `index.html` using GitHub Pages or a local static server.
